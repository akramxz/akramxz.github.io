AKRAM-LAB · cómo encaja todo

Un laboratorio, no diez ejercicios sueltos

Todos los proyectos corren en la misma red aislada de VirtualBox y se apoyan unos en otros: el servidor que bastioné en el primero es el que defiende el detector de fuerza bruta, filtra el cortafuegos y protege el DNS. El controlador de dominio de Active Directory y todos esos servicios mandan sus eventos al SIEM, que los correlaciona y avisa cuando una misma IP encadena varios ataques.

AKRAM-SIEM

Centralizar los logs de todo el laboratorio y correlacionarlos

El proyecto final del laboratorio. Escribí un SIEM en Python, sin dependencias, que recoge syslog, auth.log, el detector SSH, el DNS sinkhole, el auditor de Docker y los eventos del Active Directory mediante un agente PowerShell propio. Normaliza todo, lo guarda en SQLite y lo pasa por 15 reglas mapeadas a MITRE ATT&CK. Lo probé con eventos de laboratorio: 6 alertas en segundos, y la misma IP encadenando fuerza bruta SSH y enumeración se elevó a incidente crítico multi-fuente.

Linux CIS Hardening Auditor

Auditar servidores Linux contra el benchmark CIS

Instalé un Ubuntu Server 22.04 en mi laboratorio de VirtualBox y lo audité contra el benchmark CIS: partía de un 47,6 % de cumplimiento. Escribí un script de bastionado propio en Bash (firewall iptables con política DROP, SSH, auditd, contraseñas, bloqueo de cuentas, GRUB y kernel) con copias de seguridad y validación antes de cada cambio. Tras aplicarlo, el servidor llegó al 99,1 %, sin ninguna regresión frente a la línea base, y comprobé que cada medida funciona de verdad.

Active Directory con PowerShell

Un dominio completo para una empresa ficticia, montado solo con PowerShell

DNS Sinkhole

Escribi un servidor DNS propio, sin dependencias, que bloquea publicidad y malware respondiendo 0.0.0.0 y reenvia lo legitimo a un resolutor real. Lo probe desde Kali: 28 de 48 consultas bloqueadas. Registra cada consulta en SQLite y corre como servicio systemd. Por el camino descubri que mi propio detector de SSH del proyecto 03 bloqueaba a Kali por completo.
