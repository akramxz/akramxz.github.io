SIEM Dashboard

Centralizar logs y correlacionar eventos en tiempo real

Un panel para recibir eventos, priorizarlos y resolverlos. Ingiere logs en tiempo real, los correlaciona con reglas de umbral, secuencia y agregación, simula ataques mapeados a MITRE ATT&CK y gestiona cada alerta: reconocerla, investigarla, resolverla o descartarla como falso positivo.

Linux CIS Hardening Auditor

Auditar servidores Linux contra el benchmark CIS

Un script en Bash que revisa un servidor Debian o Ubuntu control a control: sistema de archivos, servicios, parámetros de red, registros, SSH y cuentas de usuario. Genera un informe puntuado en terminal, JSON o HTML, compara con una línea base para detectar regresiones y propone el comando que corrige cada fallo.

03

MonitorizaciónLaboratorio · 2026En desarrollo

SSH Brute Force Detector

Detectar ataques de fuerza bruta y bloquearlos en el firewall

Vigila /var/log/auth.log, cuenta los intentos fallidos de cada IP en una ventana de tiempo y responde por escalones: primero avisa, después limita las conexiones y, si el ataque continúa, bloquea la IP con nftables. Respeta una lista blanca de redes de confianza y deja registro de cada acción.

IdentidadAdaptación propia · 2026En desarrollo

Credential Rotation Enforcer, edición Active Directory

Controlar la caducidad de contraseñas y certificados en un dominio

Mi versión del proyecto para un entorno Windows. Un script en PowerShell recorre Active Directory, calcula la antigüedad de la contraseña de cada usuario y cuenta de servicio, marca las que incumplen la política y vigila la caducidad de los certificados TLS. Se ejecuta con el Programador de tareas y genera un informe en HTML.

05 · RedesEn desarrollo

DNS Sinkhole

Servidor DNS al estilo Pi-hole que bloquea dominios de malware, publicidad y C2 con listas comunitarias, registra cada consulta y cachea las respuestas respetando el TTL. Se activa en toda la red apuntando el DHCP del router a él.

Python · SQLite · systemd · Docker

Proyecto original ↗
06 · HardeningEn desarrollo

Firewall Rule Engine

Analiza reglas de iptables y nftables: detecta reglas ocultas, duplicadas o contradictorias, propone optimizaciones y genera un conjunto endurecido con política DROP por defecto, anti-spoofing y límite de ICMP.

Python · iptables · nftables

Proyecto original ↗
07 · RedesEn desarrollo

Network Traffic Analyzer

Captura tráfico en una interfaz y muestra el reparto por protocolo, los equipos que más tráfico generan y el ancho de banda de cada IP. En modo detallado enseña cada flujo con su origen y destino.

Python · Scapy · TCP/IP

08 · HardeningEn desarrollo

Docker Security Audit

Revisa contenedores, imágenes, Dockerfiles y ficheros compose contra el CIS Docker Benchmark: modo privilegiado, capacidades peligrosas o el socket de Docker montado. Exporta a JSON o SARIF para integrarlo en CI.

Python · Docker · SARIF

09 · MonitorizaciónEn desarrollo

Systemd Persistence Scanner

Busca puertas traseras en Linux en 12 categorías, como systemd, cron, SSH, LD_PRELOAD o PAM. Puntúa cada hallazgo, lo relaciona con su técnica MITRE ATT&CK y lo compara con una línea base limpia.

Python · systemd · cron
