Detector de fuerza bruta SSH

Un servicio propio que vigila los intentos de acceso por SSH y bloquea al atacante con nftables. Lo probé atacando mi servidor desde Kali con Hydra.

Objetivo

Detectar en tiempo real un ataque de fuerza bruta contra SSH y responder sin intervención humana, de forma proporcional: primero aviso, después limito y, si el ataque sigue, bloqueo la IP. Para probarlo de verdad ataco el servidor del proyecto anterior desde mi Kali con Hydra, por una red interna aislada del resto.

Entorno

MáquinaPapelRed akramlabDetalle
akram-lab-srv01Víctima y defensa10.66.0.10Ubuntu Server 22.04 bastionado en el proyecto 02 · 2 vCPU · servicio akram-ssh-guard
kaliAtacante10.66.0.50Kali Rolling · Hydra v9.6 · listas de 18 usuarios y 15 contraseñas habituales

Las dos máquinas comparten una red interna de VirtualBox (akramlab, 10.66.0.0/24) sin salida al exterior. La administración va por la red NAT, que el detector tiene en su lista blanca para no bloquearme a mí mismo.

Cómo funciona el detector

akram-ssh-guard es un servicio en Python que lee /var/log/auth.log como tail -F (sobrevive a la rotación de logs). Cada línea Failed password suma un fallo a la IP de origen en una ventana deslizante de 5 minutos. Según el número de fallos responde en tres escalones:

EscalónFallosRespuesta
Aviso3Registro en el log legible y en un fichero JSON (preparado para el SIEM del último proyecto)
Limitar6La IP entra en un conjunto nftables con caducidad de 15 minutos: solo 2 conexiones SSH nuevas por minuto
Bloquear10La IP entra en otro conjunto durante 1 hora y se descarta todo su tráfico

Usa su propia tabla inet akram_guard con prioridad -10, así actúa antes que el cortafuegos del proyecto 02 sin tocar sus reglas. Los conjuntos tienen caducidad, de modo que los bloqueos se levantan solos y no se acumulan. El servicio corre en systemd con NoNewPrivileges, ProtectSystem y solo las capacidades CAP_NET_ADMIN y CAP_DAC_READ_SEARCH.

Desbloqueo y comprobación

Un bloqueo automático también puede afectar a alguien legítimo, así que el detector tiene una orden para levantarlo a mano. Lo comprobé desde Kali antes y después.

Incidencias y soluciones

Arranque

El servidor volvió a colgarse al arrancar con 2 vCPU. El mismo fallo del instalador: el banco de pruebas del módulo raid6_pq se bloquea en VirtualBox.

El servidor no usa RAID ni btrfs, así que bloqueé raid6_pq, raid456, async_raid6_recov y btrfs en modprobe.d y regeneré el initramfs. Arranca bien con 2 vCPU.

Red de Kali

Al añadir tarjetas a Kali, mi perfil de red de clase se aplicó a la tarjeta equivocada. El perfil con IP fija 172.25.200.10 no estaba atado a ninguna interfaz y NetworkManager lo puso en la nueva tarjeta NAT, así que la redirección de puertos no llegaba.

Até ese perfil a eth0, creé un perfil propio para eth1 (10.66.0.50) y otro DHCP para eth2. Antes hice un snapshot de Kali para no perder la práctica.

Detector

Cada intento con un usuario inexistente contaba doble. sshd escribe «Invalid user» y después «Failed password» para la misma contraseña.

Solo cuento las líneas «Failed ...», que aparecen una vez por contraseña probada para cualquier usuario.

Consola

La consola de Kali tiene teclado catalán y no había mapa de teclado US. Algunos símbolos salían cambiados (el punto y coma salía como ñ).

Activé SSH en Kali para trabajar por ahí y dejé en la consola solo órdenes cortas como bash ataque.sh.

Lo que he aprendido

  • La defensa en capas funciona: el bloqueo de cuentas del proyecto 02 actuó por su cuenta sobre root, mientras el detector cortaba la IP.
  • Responder por escalones evita castigar igual un error de contraseña que un ataque. Un usuario que se equivoca dos veces no nota nada.
  • Un sistema que bloquea solo necesita una lista blanca y una forma de deshacer, o acabas bloqueándote a ti mismo.
  • nftables con conjuntos y caducidad es más limpio que añadir y borrar reglas: el bloqueo desaparece solo.
  • Escribir los eventos en JSON desde el principio facilita llevarlos después a un SIEM.

akram-ssh-guard.py · ver código
#!/usr/bin/env python3
# =============================================================================
#  akram-ssh-guard.py
#  Detector de ataques de fuerza bruta contra SSH con respuesta escalonada
#
#  Autor:    Akram El Mazzoudi Zarrouk
#  Proyecto: SSH Brute Force Detector · Laboratorio AKRAM-LAB
#
#  Lee /var/log/auth.log en tiempo real, cuenta los fallos de autenticación
#  de cada IP dentro de una ventana deslizante y responde por escalones:
#
#    1. AVISO      fallos >= UMBRAL_AVISO    -> se registra la alerta
#    2. LIMITAR    fallos >= UMBRAL_LIMITAR  -> nftables limita las conexiones
#                                               nuevas a SSH de esa IP
#    3. BLOQUEAR   fallos >= UMBRAL_BLOQUEO  -> nftables descarta todo el
#                                               tráfico de esa IP un tiempo
#
#  Usa su propia tabla nftables (inet akram_guard) con conjuntos con caducidad,
#  así no toca las reglas del cortafuegos principal del servidor.
#
#  Uso:  sudo akram-ssh-guard.py               (modo servicio)
#        sudo akram-ssh-guard.py --estado      (IPs limitadas y bloqueadas)
#        sudo akram-ssh-guard.py --desbloquear 1.2.3.4
# =============================================================================
import ipaddress
import json
import os
import re
import subprocess
import sys
import time
from collections import defaultdict, deque
from datetime import datetime

# ---------------------------------------------------------------- configuración
AUTH_LOG = "/var/log/auth.log"
LOG_EVENTOS = "/var/log/akram-ssh-guard.log"      # legible por personas
LOG_JSON = "/var/log/akram-ssh-guard.json"         # una línea JSON por evento (para un SIEM)

VENTANA_SEG = 300          # ventana deslizante de 5 minutos
UMBRAL_AVISO = 3
UMBRAL_LIMITAR = 6
UMBRAL_BLOQUEO = 10
DURACION_LIMITE = "15m"
DURACION_BLOQUEO = "1h"

LISTA_BLANCA = [
    ipaddress.ip_network("127.0.0.0/8"),
    ipaddress.ip_network("10.0.2.0/24"),   # red NAT de VirtualBox: por aquí administro yo
]

TABLA = "akram_guard"

# Líneas de sshd que indican un intento fallido. Cada patrón captura la IP.
# Solo se cuentan las líneas "Failed ...": sshd escribe una por cada contraseña probada,
# también para usuarios inexistentes o no permitidos. Las líneas "Invalid user" o
# "not allowed" acompañan a esas mismas pruebas y contarlas duplicaría los fallos.
PATRONES = [
    re.compile(r"Failed (?:password|publickey) for (?:invalid user )?(?P<user>\S+) from (?P<ip>[\d.]+)"),
]
PATRON_PAM_FAILLOCK = re.compile(r"pam_faillock\(sshd:auth\): Consecutive login failures for user (?P<user>\S+) account temporarily locked")

AZUL, VERDE, AMARILLO, NARANJA, ROJO, NC = "\033[1;34m", "\033[1;32m", "\033[1;33m", "\033[38;5;208m", "\033[1;31m", "\033[0m"


# ---------------------------------------------------------------- utilidades
def ahora():
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")


def registrar(nivel, ip, mensaje, **extra):
    color = {"INFO": AZUL, "AVISO": AMARILLO, "LIMITAR": NARANJA, "BLOQUEAR": ROJO, "OK": VERDE}.get(nivel, NC)
    linea = f"{ahora()} [{nivel:<8}] {ip:<15} {mensaje}"
    print(f"{color}{linea}{NC}", flush=True)
    with open(LOG_EVENTOS, "a") as f:
        f.write(linea + "\n")
    evento = {"ts": datetime.now().isoformat(timespec="seconds"), "host": os.uname().nodename,
              "herramienta": "akram-ssh-guard", "nivel": nivel, "ip": ip, "mensaje": mensaje, **extra}
    with open(LOG_JSON, "a") as f:
        f.write(json.dumps(evento, ensure_ascii=False) + "\n")


def nft(*args, entrada=None):
    return subprocess.run(["nft", *args], input=entrada, text=True, capture_output=True)


def en_lista_blanca(ip):
    try:
        direccion = ipaddress.ip_address(ip)
    except ValueError:
        return True
    return any(direccion in red for red in LISTA_BLANCA)


# ---------------------------------------------------------------- nftables
def preparar_nftables():
    """Crea la tabla propia con dos conjuntos con caducidad automática."""
    reglas = f"""
table inet {TABLA} {{
    set limitadas {{ type ipv4_addr; flags timeout; }}
    set bloqueadas {{ type ipv4_addr; flags timeout; }}
    chain entrada {{
        type filter hook input priority -10; policy accept;
        ip saddr @bloqueadas counter drop comment "akram-ssh-guard: bloqueo"
        ip saddr @limitadas tcp dport 22 ct state new meter limite_ssh {{ ip saddr limit rate over 2/minute }} counter drop comment "akram-ssh-guard: limite"
    }}
}}
"""
    if nft("list", "table", "inet", TABLA).returncode != 0:
        r = nft("-f", "-", entrada=reglas)
        if r.returncode != 0:
            sys.exit(f"No se pudo crear la tabla nftables: {r.stderr.strip()}")
    registrar("INFO", "-", f"Tabla nftables inet {TABLA} preparada")


def anadir(conjunto, ip, duracion):
    r = nft("add", "element", "inet", TABLA, conjunto, f"{{ {ip} timeout {duracion} }}")
    return r.returncode == 0


# ---------------------------------------------------------------- lectura del log
def seguir(ruta):
    """Lee el fichero como tail -F: desde el final y sobreviviendo a la rotación."""
    while not os.path.exists(ruta):
        time.sleep(1)
    f = open(ruta)
    f.seek(0, os.SEEK_END)
    inodo = os.fstat(f.fileno()).st_ino
    while True:
        linea = f.readline()
        if linea:
            yield linea
            continue
        time.sleep(0.3)
        try:
            if os.stat(ruta).st_ino != inodo:       # logrotate ha creado un fichero nuevo
                f.close()
                f = open(ruta)
                inodo = os.fstat(f.fileno()).st_ino
        except FileNotFoundError:
            pass


# ---------------------------------------------------------------- motor
def vigilar():
    preparar_nftables()
    fallos = defaultdict(deque)          # ip -> instantes de los fallos
    usuarios = defaultdict(set)          # ip -> usuarios probados
    escalon = defaultdict(int)           # ip -> 0 nada, 1 aviso, 2 limitada, 3 bloqueada
    registrar("INFO", "-", f"Vigilando {AUTH_LOG} · ventana {VENTANA_SEG}s · "
                           f"umbrales {UMBRAL_AVISO}/{UMBRAL_LIMITAR}/{UMBRAL_BLOQUEO}")

    for linea in seguir(AUTH_LOG):
        if "sshd" not in linea:
            continue
        m_lock = PATRON_PAM_FAILLOCK.search(linea)
        if m_lock:
            registrar("AVISO", "-", f"pam_faillock ha bloqueado la cuenta '{m_lock['user']}'", usuario=m_lock["user"])
            continue
        for patron in PATRONES:
            m = patron.search(linea)
            if not m:
                continue
            ip, usuario = m["ip"], m["user"] or "?"
            if en_lista_blanca(ip):
                break
            t = time.time()
            cola = fallos[ip]
            cola.append(t)
            usuarios[ip].add(usuario)
            while cola and t - cola[0] > VENTANA_SEG:
                cola.popleft()
            n = len(cola)
            if n == 1:                       # empieza una ventana nueva: el escalón vuelve a cero
                escalon[ip] = 0
            datos = {"fallos": n, "usuarios": sorted(usuarios[ip])[:20]}

            if n >= UMBRAL_BLOQUEO and escalon[ip] < 3:
                if anadir("bloqueadas", ip, DURACION_BLOQUEO):
                    escalon[ip] = 3
                    registrar("BLOQUEAR", ip, f"{n} fallos en {VENTANA_SEG}s · bloqueada {DURACION_BLOQUEO} "
                                              f"· usuarios probados: {len(usuarios[ip])}", **datos)
            elif n >= UMBRAL_LIMITAR and escalon[ip] < 2:
                if anadir("limitadas", ip, DURACION_LIMITE):
                    escalon[ip] = 2
                    registrar("LIMITAR", ip, f"{n} fallos · SSH limitado a 2 conexiones/min durante {DURACION_LIMITE}", **datos)
            elif n >= UMBRAL_AVISO and escalon[ip] < 1:
                escalon[ip] = 1
                registrar("AVISO", ip, f"{n} fallos de autenticación · último usuario: {usuario}", **datos)
            break


# ---------------------------------------------------------------- comandos
def estado():
    r = nft("-j", "list", "table", "inet", TABLA)
    if r.returncode != 0:
        print("La tabla no existe: el servicio no se ha iniciado.")
        return
    datos = json.loads(r.stdout)["nftables"]
    for obj in datos:
        if "set" in obj:
            s = obj["set"]
            elems = s.get("elem", [])
            print(f"{AZUL}{s['name']}{NC} ({len(elems)})")
            for e in elems:
                e = e.get("elem", e)
                ip = e["val"] if isinstance(e, dict) else e
                expira = e.get("expires", "?") if isinstance(e, dict) else "?"
                print(f"   {ip:<15}  caduca en {expira}s")
        if "rule" in obj and "comment" in obj["rule"]:
            for expr in obj["rule"]["expr"]:
                if "counter" in expr:
                    c = expr["counter"]
                    print(f"   {obj['rule']['comment']}: {c['packets']} paquetes descartados")


def desbloquear(ip):
    for conjunto in ("bloqueadas", "limitadas"):
        nft("delete", "element", "inet", TABLA, conjunto, f"{{ {ip} }}")
    registrar("OK", ip, "Desbloqueada manualmente")


if __name__ == "__main__":
    if os.geteuid() != 0:
        sys.exit("Ejecuta este programa como root.")
    if "--estado" in sys.argv:
        estado()
    elif "--desbloquear" in sys.argv:
        desbloquear(sys.argv[sys.argv.index("--desbloquear") + 1])
    else:
        try:
            vigilar()
        except KeyboardInterrupt:
            registrar("INFO", "-", "Detenido")

# Ataque de fuerza bruta SSH de laboratorio · Akram El Mazzoudi Zarrouk
# Origen: kali (10.66.0.50) · Destino: akram-lab-srv01 (10.66.0.10) · red interna akramlab
clear
printf '\033[1;31m'
echo "==============================================================="
echo "  AKRAM-LAB · Proyecto 03 · Ataque de fuerza bruta SSH"
echo "  Laboratorio de Akram El Mazzoudi Zarrouk"
echo "  Atacante: $(hostname) $(ip -4 -br a show eth1 | awk '{print $3}')  ->  Objetivo: 10.66.0.10:22"

printf '\033[0m'
echo "Usuarios: $(wc -l < ~/akramlab/usuarios.txt) · Contraseñas: $(wc -l < ~/akramlab/claves.txt) · $(date '+%d/%m/%Y %H:%M:%S')"

timeout 180 stdbuf -oL hydra -L ~/akramlab/usuarios.txt -P ~/akramlab/claves.txt -t 4 -w 10 -I -V ssh://10.66.0.10 2>&1 | tee ~/akramlab/hydra-salida.txt | grep --line-buffered -E "ATTEMPT|host:|rror|finished|completed|timeout|refused|could not"
echo; echo "Fin del ataque: $(date +%H:%M:%S) · intentos enviados: $(grep -c ATTEMPT ~/akramlab/hydra-salida.txt)"

#!/usr/bin/env bash
# Comprobación de acceso a SSH de akram-lab-srv01 · Akram El Mazzoudi Zarrouk
printf '\033[1;36m%s\033[0m\n' "[Akram El Mazzoudi] $(date +%H:%M:%S) · ¿Puede kali (10.66.0.50) abrir SSH en 10.66.0.10?"
if timeout 6 bash -c 'exec 3<>/dev/tcp/10.66.0.10/22 && head -c 21 <&3' 2>/dev/null; then
    echo; printf '\033[1;32m%s\033[0m\n' "  -> SÍ: el puerto 22 responde"
else
    printf '\033[1;31m%s\033[0m\n' "  -> NO: sin respuesta en 6 s (el detector descarta mis paquetes)"
fi
