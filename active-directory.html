Active Directory con PowerShell

Un dominio completo para una empresa ficticia, montado solo con PowerShell en un Windows Server Core, y un informe que revisa su higiene. Lo probé con una cuenta mal configurada a propósito.

Objetivo

Montar desde cero un dominio de Active Directory para una empresa ficticia, Akram Solutions, como lo haría un administrador de sistemas: todo con PowerShell, de forma repetible y siguiendo las buenas prácticas (modelo AGDLP, cuentas de administración separadas, políticas de contraseña por niveles, GPOs de seguridad y auditoría). Después, escribir un informe que revise la higiene del dominio y comprobar que de verdad detecta los errores típicos.

Antes de tocar nada guardé una instantánea de la VM tal como estaba en clase, y otras dos a mitad del proyecto (bosque creado y estructura completa).

1. Crear el bosque

Primero preparo el servidor (nombre, IP, DNS, zona horaria) y después instalo AD DS y promociono el servidor con Install-ADDSForest. Al ser Server Core, todo se hace por consola.

3. Informe de higiene del dominio

akram-ad-informe.ps1 resume el dominio (OUs, usuarios por departamento, miembros de grupos privilegiados, políticas y PSO) y revisa los fallos más comunes, cada uno con su gravedad y su motivo:

  • Cuentas no previstas con privilegios de dominio.
  • Usuarios con SPN (kerberoasting) y sin preautenticación Kerberos (AS-REP roasting).
  • Equipos con delegación sin restringir.
  • Contraseñas que no caducan y contraseñas escritas en la descripción.
  • Cuentas inactivas más de 90 días o creadas y nunca usadas.
  • Política de contraseñas débil, sin bloqueo o sin papelera de AD.

En el dominio recién montado no encuentra nada. Pero un informe limpio no demuestra que funcione, así que lo probé: h.ps1 crea una cuenta de servicio de prueba, svc-backup-prueba, con 4 errores a propósito (SPN, clave que no caduca, sin preautenticación y la clave en la descripción).

Mientras tanto, el agente del DC mandó el evento 4720 al SIEM y este disparó la alerta «Cuenta de usuario creada» (T1136.002) indicando que la había creado akram.admin. Así los dos proyectos quedan conectados.

Incidencias y soluciones

Un informe que nunca encontraba nada

La primera prueba con la cuenta mal configurada devolvió «Ninguno» junto a una ristra de errores de Get-History.

Había llamado H a la función que guarda cada hallazgo, y en PowerShell h es el alias de Get-History: los alias se resuelven antes que las funciones. El informe nunca podía registrar un hallazgo. La renombré a Hallazgo y dejé el aviso en el código. Sin la prueba con errores a propósito, habría dado por bueno un dominio sin revisarlo de verdad.

Windows en español

auditpol devolvía «error 0x57: el parámetro no es correcto» en todas las subcategorías.

Los nombres de las subcategorías cambian con el idioma del sistema. Las activo por su GUID, que es igual en cualquier idioma. Hice lo mismo con los grupos integrados (Admins. del dominio, Administradores…): los busco por SID y no por nombre.

Permisos de bosque

Activar la papelera de AD fallaba por permisos con la cuenta local con la que había promocionado el servidor.

Es un cambio de bosque y solo lo puede hacer un Administrador de empresa. Metí mi cuenta Tier 0 akram.admin en ese grupo y la activé con ella, que es como debe administrarse el dominio.

Agente del SIEM

Al SIEM llegaban inicios de sesión vacíos, sin usuario ni tipo.

En el agente usaba continue dentro de un switch para saltar los inicios de sesión del sistema, pero en PowerShell ese continue solo sale del switch, no del bucle. Lo cambié por una marca y ahora solo se envían los eventos que interesan.

Server Core sin escritorio

La consola de la VM perdía teclas cuando el servidor iba cargado, y las órdenes largas llegaban cortadas.

Monté en SRV01 un pequeño servidor de ficheros solo para la red del laboratorio: el DC descarga los scripts con una orden corta y sube los resultados por HTTP. En pantalla solo escribo una línea.

Tildes rotas

El separador «·» salía como «Â·» en las capturas.

PowerShell 5.1 lee los .ps1 en UTF-8 sin BOM como ANSI. Guardo los scripts con BOM.

Lo que he aprendido

  • AGDLP parece burocracia, pero hace que dar o quitar un permiso sea mover a alguien de grupo y no tocar ACLs de carpetas.
  • Separar la cuenta de administración (Tier 0) de la del día a día, con su propia PSO más estricta, es de lo más barato que reduce el riesgo.
  • En entornos en otro idioma hay que trabajar con SIDs y GUIDs, nunca con nombres traducidos.
  • Un control de seguridad que no se ha probado con un caso que debería fallar no está probado. El fallo del alias lo demuestra.
  • Kerberoasting y AS-REP roasting no necesitan explotar nada: basta un SPN en un usuario o una casilla mal marcada.

<#
  01-preparar-servidor.ps1 - Paso 1: dejar el servidor listo para ser controlador de dominio
  Autor:    Akram El Mazzoudi Zarrouk
  Proyecto: Active Directory + PowerShell - Laboratorio AKRAM-LAB

  - IP fija en la red del laboratorio (akramlab 10.66.0.0/24)

$ErrorActionPreference = 'Stop'

# La tarjeta de la red interna es la que no recibe DHCP del NAT de VirtualBox
$nic = Get-NetAdapter | Where-Object Status -eq 'Up' |
       Where-Object { -not (Get-NetIPAddress -InterfaceIndex $_.ifIndex -AddressFamily IPv4 -ErrorAction SilentlyContinue |
                            Where-Object IPAddress -like '10.0.2.*') } | Select-Object -First 1
Rename-NetAdapter -Name $nic.Name -NewName 'LAN-AKRAMLAB'
Get-NetIPAddress -InterfaceAlias 'LAN-AKRAMLAB' -AddressFamily IPv4 -ErrorAction SilentlyContinue | Remove-NetIPAddress -Confirm:$false
New-NetIPAddress -InterfaceAlias 'LAN-AKRAMLAB' -IPAddress 10.66.0.20 -PrefixLength 24 | Out-Null
Set-DnsClientServerAddress -InterfaceAlias 'LAN-AKRAMLAB' -ServerAddresses 127.0.0.1

$nat = Get-NetAdapter | Where-Object Name -ne 'LAN-AKRAMLAB' | Select-Object -First 1
Rename-NetAdapter -Name $nat.Name -NewName 'NAT-ADMIN'

Set-TimeZone -Id 'Romance Standard Time'
# Permitir ping desde la red del laboratorio (util para diagnosticar)
Enable-NetFirewallRule -Name 'FPS-ICMP4-ERQ-In' -ErrorAction SilentlyContinue

Rename-Computer -NewName 'DC01-AKRAM' -Force
Write-Output 'Servidor preparado: 10.66.0.20 / DC01-AKRAM. Reiniciando...'
Restart-Computer -Force

$dn    = $dom.DistinguishedName          # DC=akramlab,DC=local

$log   = 'C:\AkramLab\03-estructura.log'
$daSid  = "$($dom.DomainSID)-512"                                   # Admins. del dominio (en cualquier idioma)
$daNom  = (Get-ADGroup $daSid).Name
function Nombre($sid) { (New-Object Security.Principal.SecurityIdentifier $sid).Translate([Security.Principal.NTAccount]).Value }
function Paso($t) { $l = "[{0:HH:mm:ss}] {1}" -f (Get-Date), $t; Write-Output $l; Add-Content $log $l }
function OU($nombre, $padre, $desc) {
  if (-not (Get-ADOrganizationalUnit -Filter "Name -eq '$nombre'" -SearchBase $padre -SearchScope OneLevel -ErrorAction SilentlyContinue)) {
    New-ADOrganizationalUnit -Name $nombre -Path $padre -Description $desc -ProtectedFromAccidentalDeletion $true
  }
  "OU=$nombre,$padre"
}
function Grupo($nombre, $ambito, $ou, $desc) {
  if (-not (Get-ADGroup -Filter "Name -eq '$nombre'" -ErrorAction SilentlyContinue)) {
    New-ADGroup -Name $nombre -GroupScope $ambito -GroupCategory Security -Path $ou -Description $desc
  }
}
function Clave { # contrasena temporal aleatoria que cumple la complejidad
  $c = 'ABCDEFGHJKLMNPQRSTUVWXYZ', 'abcdefghijkmnpqrstuvwxyz', '23456789', '!$%*+?'
  -join (($c | ForEach-Object { $_[(Get-Random -Max $_.Length)] }) + (1..10 | ForEach-Object { ($c -join '')[(Get-Random -Max 62)] }) | Sort-Object { Get-Random })
}

Paso '4. Carpetas compartidas con permisos AGDLP'
$base = 'C:\Datos'
$compartidas = @{
  'Proyectos' = @{ RW = 'DL_Proyectos_RW'; R = 'DL_Proyectos_R' }
  'Nominas'   = @{ RW = 'DL_Nominas_RW' }
  'Comun'     = @{ RW = 'DL_Comun_RW' }

foreach ($c in $compartidas.Keys) {
  $ruta = Join-Path $base $c
  New-Item $ruta -ItemType Directory -Force | Out-Null
  $acl = Get-Acl $ruta
  $acl.SetAccessRuleProtection($true, $false)                     # sin herencia
  foreach ($sid in 'S-1-5-32-544', 'S-1-5-18') {                 # Administradores y SYSTEM
    $acl.AddAccessRule((New-Object Security.AccessControl.FileSystemAccessRule((New-Object Security.Principal.SecurityIdentifier $sid), 'FullControl', 'ContainerInherit,ObjectInherit', 'None', 'Allow')))
  }
  $acl.AddAccessRule((New-Object Security.AccessControl.FileSystemAccessRule("AKRAMLAB\$($compartidas[$c].RW)", 'Modify', 'ContainerInherit,ObjectInherit', 'None', 'Allow')))
  if ($compartidas[$c].R) {
    $acl.AddAccessRule((New-Object Security.AccessControl.FileSystemAccessRule("AKRAMLAB\$($compartidas[$c].R)", 'ReadAndExecute', 'ContainerInherit,ObjectInherit', 'None', 'Allow')))

    New-SmbShare -Name $c -Path $ruta -FullAccess (Nombre $daSid) -ChangeAccess (Nombre 'S-1-5-11') -FolderEnumerationMode AccessBased | Out-Null
  }
}

Paso '6. GPOs de seguridad'
function GPO($nombre, $ou, $comentario, [scriptblock]$valores) {
  $g = Get-GPO -Name $nombre -ErrorAction SilentlyContinue
  if (-not $g) { $g = New-GPO -Name $nombre -Comment $comentario }
  & $valores $nombre
  if (-not (Get-GPInheritance -Target $ou).GpoLinks.DisplayName -contains $nombre) { New-GPLink -Name $nombre -Target $ou | Out-Null }
}
GPO 'AKRAM-Seguridad-Base' $raiz 'Endurecimiento comun para toda la empresa' {
  param($n)
  # Sin LLMNR ni NetBIOS-NS: evita el envenenamiento tipo Responder
  Set-GPRegistryValue -Name $n -Key 'HKLM\Software\Policies\Microsoft\Windows NT\DNSClient' -ValueName EnableMulticast -Type DWord -Value 0 | Out-Null
  # SMB firmado obligatorio (cliente y servidor)
  Set-GPRegistryValue -Name $n -Key 'HKLM\System\CurrentControlSet\Services\LanmanWorkstation\Parameters' -ValueName RequireSecuritySignature -Type DWord -Value 1 | Out-Null
  Set-GPRegistryValue -Name $n -Key 'HKLM\System\CurrentControlSet\Services\LanManServer\Parameters' -ValueName RequireSecuritySignature -Type DWord -Value 1 | Out-Null
  # Solo NTLMv2, rechazar LM y NTLMv1
  Set-GPRegistryValue -Name $n -Key 'HKLM\System\CurrentControlSet\Control\Lsa' -ValueName LmCompatibilityLevel -Type DWord -Value 5 | Out-Null
  # Registro de PowerShell (bloques de script) para el SIEM
  Set-GPRegistryValue -Name $n -Key 'HKLM\Software\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging' -ValueName EnableScriptBlockLogging -Type DWord -Value 1 | Out-Null
}
GPO 'AKRAM-Usuarios-Puesto' $ouUsu 'Ajustes de puesto para empleados' {
  param($n)
  # Bloqueo de pantalla a los 10 minutos con contrasena
  Set-GPRegistryValue -Name $n -Key 'HKCU\Software\Policies\Microsoft\Windows\Control Panel\Desktop' -ValueName ScreenSaveActive -Type String -Value '1' | Out-Null
  Set-GPRegistryValue -Name $n -Key 'HKCU\Software\Policies\Microsoft\Windows\Control Panel\Desktop' -ValueName ScreenSaverIsSecure -Type String -Value '1' | Out-Null
  Set-GPRegistryValue -Name $n -Key 'HKCU\Software\Policies\Microsoft\Windows\Control Panel\Desktop' -ValueName ScreenSaveTimeOut -Type String -Value '600' | Out-Null
  # Sin acceso al registro ni a la consola para usuarios normales
  Set-GPRegistryValue -Name $n -Key 'HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System' -ValueName DisableRegistryTools -Type DWord -Value 1 | Out-Null
  Set-GPRegistryValue -Name $n -Key 'HKCU\Software\Policies\Microsoft\Windows\System' -ValueName DisableCMD -Type DWord -Value 2 | Out-Null
}
GPO 'AKRAM-Ventas-USB' $ouDep['Ventas'] 'Ventas no puede usar memorias USB (datos de clientes)' {
  param($n)
  Set-GPRegistryValue -Name $n -Key 'HKLM\Software\Policies\Microsoft\Windows\RemovableStorageDevices' -ValueName Deny_All -Type DWord -Value 1 | Out-Null
}

<#
  akram-ad-informe.ps1 - Informe de estado y seguridad del dominio
  Autor:    Akram El Mazzoudi Zarrouk
  Proyecto: Active Directory + PowerShell - Laboratorio AKRAM-LAB

  Resume como esta el dominio y revisa los fallos de higiene mas comunes:
  cuentas privilegiadas, contrasenas que no caducan, cuentas inactivas o
  sin estrenar, kerberoasting (SPN en usuarios), delegacion sin restringir,
  usuarios sin preautenticacion Kerberos y contrasenas en la descripcion.
  Uso:  .\akram-ad-informe.ps1  [-Json C:\AkramLab\informe-ad.json]
#>
param([string]$Json)
Import-Module ActiveDirectory, GroupPolicy
# Ojo: no llamar "H" a la funcion de hallazgos; "h" es el alias de Get-History y los alias ganan a las funciones
$dom = Get-ADDomain; $bos = Get-ADForest
$todos = Get-ADUser -Filter * -Properties Enabled, LastLogonDate, PasswordNeverExpires, PasswordLastSet, Description, `
         ServicePrincipalName, DoesNotRequirePreAuth, TrustedForDelegation, Department, whenCreated, AdminCount
$personas = $todos | Where-Object { $_.SamAccountName -notin 'krbtgt', 'Guest', 'Invitado' }
$hall = New-Object System.Collections.Generic.List[object]
function Hallazgo($sev, $control, $quien, $porque) { $hall.Add([pscustomobject]@{ Gravedad = $sev; Control = $control; Objetos = $quien; Motivo = $porque }) }

Write-Host ("AKRAM-AD · [Akram El Mazzoudi] · {0} · {1:dd/MM/yyyy HH:mm}" -f $dom.DNSRoot, (Get-Date)) -ForegroundColor Cyan
Write-Host ("  Bosque {0} · nivel {1} · DC {2} · {3} OUs · {4} usuarios · {5} grupos · {6} GPOs" -f $bos.Name, $dom.DomainMode,
  (Get-ADDomainController).HostName, @(Get-ADOrganizationalUnit -Filter *).Count, @($personas).Count,
  @(Get-ADGroup -Filter *).Count, @(Get-GPO -All).Count) -ForegroundColor DarkGray

# --- Inventario por departamento ---------------------------------------------
Write-Host "`n  Usuarios por departamento" -ForegroundColor Cyan
$personas | Where-Object Department | Group-Object Department | Sort-Object Count -Descending |
  ForEach-Object { Write-Host ("    {0,-14} {1,3}  {2}" -f $_.Name, $_.Count, ('#' * $_.Count)) }

# --- Grupos privilegiados ------------------------------------------------------
$daSid = "$($dom.DomainSID)-512"; $eaSid = "$($bos.RootDomain | ForEach-Object { (Get-ADDomain $_).DomainSID })-519"
$priv = foreach ($sid in $daSid, $eaSid, 'S-1-5-32-544') {
  $g = Get-ADGroup -Filter "SID -eq '$sid'"
  if ($g) { Get-ADGroupMember $g -Recursive | Where-Object objectClass -eq 'user' | Select-Object @{n = 'Grupo'; e = { $g.Name } }, SamAccountName }
}
Write-Host "`n  Miembros de grupos privilegiados" -ForegroundColor Cyan
$priv | Sort-Object SamAccountName -Unique | ForEach-Object { Write-Host ("    {0,-22} en {1}" -f $_.SamAccountName, $_.Grupo) }
$extra = $priv | Where-Object SamAccountName -notin 'Administrador', 'Administrator', 'akram.admin', 'windowserver' | Sort-Object SamAccountName -Unique
if ($extra) { Hallazgo 'ALTA' 'Cuentas no previstas con privilegios de dominio' ($extra.SamAccountName -join ', ') 'Solo las cuentas Tier 0 deberian administrar el dominio' }

# --- Revisiones de higiene ----------------------------------------------------
$x = $personas | Where-Object { $_.Enabled -and $_.PasswordNeverExpires }
if ($x) { Hallazgo 'MEDIA' 'Contrasena que nunca caduca' ($x.SamAccountName -join ', ') 'Si se filtra, sirve para siempre' }
$x = $personas | Where-Object { $_.Enabled -and $_.ServicePrincipalName }
if ($x) { Hallazgo 'ALTA' 'Usuarios con SPN (kerberoastables)' ($x.SamAccountName -join ', ') 'Cualquiera del dominio puede pedir su ticket y crackearlo offline' }
$x = $personas | Where-Object DoesNotRequirePreAuth
if ($x) { Hallazgo 'ALTA' 'Sin preautenticacion Kerberos (AS-REP roasting)' ($x.SamAccountName -join ', ') 'Se puede obtener un hash sin conocer la contrasena' }
$x = Get-ADComputer -Filter { TrustedForDelegation -eq $true -and PrimaryGroupID -ne 516 }
if ($x) { Hallazgo 'ALTA' 'Equipos con delegacion sin restringir' ($x.Name -join ', ') 'Guardan tickets TGT de quien se conecte' }
$x = $personas | Where-Object { $_.Description -match 'pass|contra|clave|pwd' }
if ($x) { Hallazgo 'ALTA' 'Contrasena en el campo descripcion' ($x.SamAccountName -join ', ') 'La descripcion la puede leer cualquier usuario del dominio' }
$x = $personas | Where-Object { $_.Enabled -and $_.LastLogonDate -and $_.LastLogonDate -lt (Get-Date).AddDays(-90) }
if ($x) { Hallazgo 'MEDIA' 'Cuentas inactivas mas de 90 dias' ($x.SamAccountName -join ', ') 'Cuentas olvidadas = puerta trasera' }
$x = $personas | Where-Object { $_.Enabled -and -not $_.LastLogonDate -and $_.whenCreated -lt (Get-Date).AddDays(-30) }
if ($x) { Hallazgo 'BAJA' 'Cuentas creadas hace mas de 30 dias sin estrenar' ($x.SamAccountName -join ', ') 'Revisar si siguen haciendo falta' }
$pol = Get-ADDefaultDomainPasswordPolicy
if ($pol.MinPasswordLength -lt 10) { Hallazgo 'MEDIA' 'Longitud minima de contrasena baja' $pol.MinPasswordLength 'Recomendado 10 o mas' }
if ($pol.LockoutThreshold -eq 0) { Hallazgo 'ALTA' 'Sin bloqueo de cuentas' '-' 'Permite fuerza bruta ilimitada' }
if (-not (Get-ADOptionalFeature 'Recycle Bin Feature').EnabledScopes) { Hallazgo 'BAJA' 'Papelera de reciclaje de AD desactivada' '-' 'Un borrado accidental no se puede deshacer facilmente' }

Write-Host "`n  Politica del dominio: minimo $($pol.MinPasswordLength) caracteres · bloqueo a los $($pol.LockoutThreshold) intentos durante $($pol.LockoutDuration.TotalMinutes) min" -ForegroundColor DarkGray
$pso = Get-ADFineGrainedPasswordPolicy -Filter *
foreach ($p in $pso) { Write-Host "  PSO $($p.Name): minimo $($p.MinPasswordLength) caracteres · bloqueo a los $($p.LockoutThreshold) intentos" -ForegroundColor DarkGray }

Write-Host "`n  Hallazgos de seguridad" -ForegroundColor Cyan
if (-not $hall.Count) { Write-Host '    Ninguno. El dominio pasa todas las revisiones.' -ForegroundColor Green }
$col = @{ ALTA = 'Red'; MEDIA = 'Yellow'; BAJA = 'Cyan' }
foreach ($h in $hall | Sort-Object { @{ALTA = 0; MEDIA = 1; BAJA = 2 }[$_.Gravedad] }) {
  Write-Host ("    {0,-6}" -f $h.Gravedad) -ForegroundColor $col[$h.Gravedad] -NoNewline
  Write-Host (" {0}: {1}" -f $h.Control, $h.Objetos)
  Write-Host ("           {0}" -f $h.Motivo) -ForegroundColor DarkGray
}
if ($Json) {
  [pscustomobject]@{ autor = 'Akram El Mazzoudi Zarrouk'; dominio = $dom.DNSRoot; fecha = (Get-Date).ToString('s')
    usuarios = @($personas).Count; hallazgos = $hall } | ConvertTo-Json -Depth 4 | Set-Content $Json -Encoding UTF8
}
